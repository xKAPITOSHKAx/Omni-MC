# Omni MC для OBS Studio

Версия плагина: **v1.3.5**. Проверенная версия OBS: 32.1.0, Windows x64.

## Использование

1. Перезапустите OBS.
2. Откройте меню панелей OBS и включите **Omni MC**. Также доступны **Сервис → Omni MC — Музыкальный плеер** и локальная страница `http://127.0.0.1:17843/`.
3. Запустите музыку в Spotify, Яндекс Музыке, браузере или проигрывателе Windows. Выберите появившуюся медиасессию либо оставьте автоматический выбор.
4. Настройте скин, фон, размытие, цвета, прозрачность и яркость. Автопоказ показывает плеер на выбранное время при смене трека. Без автопоказа плеер виден постоянно. Кнопка теста показывает его на пять секунд.
5. Нажмите **Добавить плеер в OBS**. В текущей сцене появится отдельный браузерный источник **Omni MC — Плеер [идентификатор сцены]**. Его размер определяется скином. Повторное нажатие использует источник этой сцены.

У каждой сцены свои настройки: выбранная музыка, скин, фон, цвета, размеры текста, автопоказ и эффекты появления. При переключении сцены панель автоматически загружает её настройки. Они сохраняются в `%APPDATA%\obs-studio\plugin_config\omni-mc\scenes\[UUID сцены].json`. Общий `settings.json` используется для первоначального переноса настроек старой версии. Старые общие плееры автоматически заменяются отдельными источниками с сохранением положения, масштаба, обрезки и видимости.

В блоке автопоказа доступен переключатель **Скрыть если ничего не играет**. При паузе, остановке или отсутствии выбранной медиасессии он скрывает карточку вместе с фоном Composite Blur. При воспроизведении плеер показывается с учётом настроенного автопоказа. Кнопка теста позволяет показать плеер и без музыки. По умолчанию переключатель выключен.

Показ и скрытие этим переключателем используют выбранный эффект **Появление**: слева, справа, снизу или плавно. Переход длится 500 мс; карточка и фон используют общее время анимации. При смене состояния во время перехода новая анимация продолжается от текущей прозрачности.

## Совместимость

Приложение должно передавать медиасессию Windows System Media Transport Controls. Название, исполнитель, обложка, длительность и управление доступны в объёме, который предоставляет само приложение. Браузер может отображаться своим именем, например Chrome. Если приложение не передаёт медиасессию, оно не появится в списке. Плагин не распознаёт треки по звуку.

Плеер показывает информацию о музыке. Для передачи самого звука используйте захват звука приложения или звук рабочего стола в OBS.

Фон обрабатывается в каждом кадре нативным фильтром **Omni MC — Фон (Composite Blur)**, автоматически добавляемым к плееру. Установлен Composite Blur 1.5.2. Размывается только участок выбранного источника или сцены под плеером, с учётом положения и масштаба. Фон ограничен скруглённой карточкой; текст и обложка остаются чёткими. Браузер не получает снимки фона и не использует CSS blur. При захвате сцены плеер исключается из фона, чтобы предотвратить обратную связь. Для фона плеер должен находиться в текущей сцене.

Панель использует встроенный браузер OBS и работает без внешнего сайта. Плагин слушает только `127.0.0.1:17843`; этот порт должен быть свободен. После закрытия OBS локальная страница недоступна.

## Исходный код

Основной код плагина находится в `src`, а HTML, CSS и JavaScript — в `web`. Файл ресурсов `omni-mc.rc` встраивает содержимое папки `web` внутрь DLL. Код использует C++17, Windows SDK и C++/WinRT. Исходные файлы сохранены в UTF-8 без BOM.

При завершении встроенный браузер сначала отсоединяется от панели и удаляется через DeferredDelete, пока контейнер и его layout ещё существуют. Затем удаляется контейнер панели. Это предотвращает обработку событий CEF внутри деструктора уже разрушаемой закреплённой панели.

Дополнительные скины: **Винил** (360 × 380, вращающийся диск с обложкой в центре), **Стекло** (360 × 420, обложка с нижней карточкой), **Постер** (360 × 360, квадратная обложка с информацией и управлением), **Кино** (640 × 360, широкая обложка с нижней полосой) и **Дуэт** (360 × 460, отдельные обложка и панель управления). Винил вращается при воспроизведении и сохраняет угол при паузе. При смене скина существующий браузерный источник автоматически меняет размер и перезагружает оформление. Добавлять его заново не требуется.

В списке эффектов появления также доступен вариант **Сверху**. Он применяется к автопоказу и скрытию при отсутствии музыки, вместе с нативным размытым фоном.

Прогресс рассчитывается по позиции и LastUpdatedTime медиасессии без ограничения десятью секундами, с учётом скорости воспроизведения. Интерфейс обновляет полосу через requestAnimationFrame между ответами сервера. В браузерном источнике прошедшее время расположено слева под полосой, длительность справа.
